# LocalKit privacy statement

LocalKit processes selected content on the Android device.

- No internet permission
- No advertising
- No analytics or telemetry
- No user account
- No remote server
- No sale or sharing of data

The app stores only favorites and recent tool identifiers in local Android preferences. It does not store generated passwords. Camera frames are processed while camera tools are open. User-selected files are read only for the requested operation, and exported files are written only to destinations chosen through Android's system picker.

Uninstalling the app removes its preferences and temporary cache. User-exported files remain where the user saved them.
